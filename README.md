A Python script that add dates in the beginning of the .msg files in a folder.

__What the script does:__
The script will ask the user for a path where the .msg files are stored. It will then add the date in the beginning of the file name.
The date that is added in the .msg file name is in the format 'YYYY-MM-DD' and the date is when the .msg file was sent. If the .msg file does not have a date, the current date will be used.
